# Results: Phase 5 Tiling & Adaptive Quality Allocation

This directory stores outputs generated during Phase 5 (Tile Prediction and Adaptive Quality Allocation):

1. **Tile Partition Metadata:** Segment and tile boundary geometry CSVs.
2. **Viewport-to-Tile Hit Ratios:** Accuracy and recall tables of predicted vs. actual viewed tiles.
3. **Adaptive Bitrate Allocation Logs:** Simulated bandwidth consumption, utility scores, and QoE metrics under dynamic network traces.
4. **Bandwidth Savings Comparisons:** Empirical comparisons against monolithic non-tiled 360° streaming baselines.
