2. MODEL INPUT & TARGET CONFIGURATION
--------------------------------------------------------------------------------
- Input Sequence Length (L):     10 historical steps (~1.0 second at 10 Hz)
- Prediction Horizon (k):         5 steps ahead (~0.5 seconds into the future)
- Number of Input Features:       7 features
- Input Feature Names:
  1. sin_yaw   : sin(radians(yaw)) -> circular representation
  2. cos_yaw   : cos(radians(yaw)) -> circular representation
  3. pitch     : pitch angle (degrees)
  4. yaw_vel   : yaw angular velocity (deg/s, calculated with unwrapped yaw)
  5. pitch_vel : pitch angular velocity (deg/s)
  6. yaw_acc   : yaw angular acceleration (deg/s²)
  7. pitch_acc : pitch angular acceleration (deg/s²)

- Target Representation (y):
  - Shape: (N, 3)
  - y[:, 0] = sin(radians(future_yaw))
  - y[:, 1] = cos(radians(future_yaw))
  - y[:, 2] = future_pitch (degrees)
  - Raw Target Degrees Array (y_deg): Shape (N, 2) containing [future_yaw_deg, future_pitch_deg] for direct degree MAE evaluation during testing.
